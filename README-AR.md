# StickSongs Finds — دليل التشغيل بالعربي

الموقع ده نسخة أولية ثابتة (HTML/CSS/JavaScript) ومصممة للموبايل. مفيش اشتراك مطلوب لتشغيل الملفات نفسها. الاستضافة المجانية تعتمد على شروط وحدود المنصة.

## قبل النشر
- افتح `products.json` وعدّل المنتجات التجريبية.
- كل منتج له الحقول دي:
  - `id`: اسم قصير مميز بالإنجليزي، من غير مسافات.
  - `name`: اسم المنتج.
  - `category`: استخدم `Tech` أو `Home` أو `Everyday` عشان أزرار التصنيف تشتغل.
  - `description`: وصف قصير من كتابتك.
  - `image`: رابط مباشر لصورة مسموح لك باستخدامها.
  - `amazonUrl`: رابط Amazon Affiliate الكامل الخاص بيك. سيبه فاضي لحد ما تحط الرابط الصحيح.
  - `price`: اختياري؛ سيبه فاضي لو مش متأكد من قواعد عرض الأسعار.
  - `tag`: كلمة قصيرة تظهر على الصورة.
- انسخ عنصر منتج كامل داخل القائمة، وافصل بين المنتجات بفاصلة `,`، وتأكد إن ملف JSON صحيح.
- أزرار Amazon هتفضل تعرض `ADD AMAZON LINK` لو الرابط فاضي، ومش هتفتح لينك وهمي.

## نشر مجاني باستخدام GitHub + Cloudflare Pages
1. اعمل حساب GitHub لو معندكش، ثم أنشئ Repository جديد باسم `sticksongs-site`.
2. ارفع الملفات الخمسة الأساسية للموقع: `index.html`, `styles.css`, `app.js`, `products.json`, و`README-AR.md` إلى جذر المستودع (root).
3. اعمل حساب Cloudflare وافتح Workers & Pages ثم أنشئ Pages project مربوط بـ GitHub.
4. اختار المستودع `sticksongs-site`.
5. لأنه موقع ثابت من غير build framework، اترك Build command فارغًا (لو الواجهة تسمح) واستخدم مجلد الإخراج `/` أو `.` حسب الخيارات المعروضة. لو الواجهة الحالية مختلفة، راجع تعليمات Cloudflare Pages للمواقع الثابتة.
6. اضغط Deploy. بعد النشر هتاخد رابطًا مجانيًا ينتهي بـ `pages.dev` إذا كان الاسم متاحًا.
7. كل مرة تعدّل `products.json` وتعمل Commit/Push على GitHub، Cloudflare يعيد نشر الموقع تلقائيًا.

## ملاحظات مهمة
- الاسم `sticksongs.pages.dev` مجرد اسم مقترح؛ التوفر غير مضمون.
- ما تحطش بيانات دخول أو كلمات سر أو معلومات خاصة داخل الملفات.
- استخدم صورًا عندك حق استخدامها، والتزم بسياسات Amazon Associates وإفصاح العمولة. الإفصاح الموجود في أسفل الصفحة مثال أولي، وقد تحتاج تضيف إفصاحًا واضحًا بالقرب من الروابط وبيان العلاقة بالعمولة وفق متطلبات البرنامج.
- الأسعار والتقييمات لا تُحدّث تلقائيًا. لا تضفها إلا إذا كنت قادرًا على عرضها وفق شروط Amazon.
- ده كتالوج روابط أفلييت، مش متجر بيع أو دفع إلكتروني.
